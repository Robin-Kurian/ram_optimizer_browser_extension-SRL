# Stackroot Tab Saver

Stackroot Tab Saver is a Chromium extension that frees memory by discarding inactive tabs and organizing them in a Frozen tab group.

## Load locally

1. Open the browser's extensions page (`chrome://extensions` in Chrome or `brave://extensions` in Brave).
2. Enable Developer mode and choose **Load unpacked**.
3. Select `browser-ram-optimizer-srl-1.0.0-webstore`.
