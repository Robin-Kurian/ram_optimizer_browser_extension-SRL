# Ram Optimizer -SRL

Ram Optimizer -SRL is a Chromium extension that frees memory by discarding inactive tabs and organizing them in a Frozen tab group.

## Load locally

1. Open the browser's extensions page (`chrome://extensions` in Chrome or `brave://extensions` in Brave).
2. Enable Developer mode and choose **Load unpacked**.
3. Select `ram_optimizer_browser_extension-SRL`.
